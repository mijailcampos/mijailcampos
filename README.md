### Hi, I'm José Mijail Campos Compeán 👋

Bioinformatics scientist in Mexico City working on **microbiome metabarcoding (16S/18S rRNA)**, reproducible NGS pipelines and bioinformatics software. PhD candidate in Biological and Health Sciences, and founder of **[Bioagens](https://bioagens.com)**, a web platform of bioinformatics tools for genomic and metagenomic research.

#### 🔬 What I'm working on

- **[MetagenApp](https://github.com/mijailcampos/metagenapp)**: a reproducible 16S/18S metabarcoding pipeline (VSEARCH + Wang-style naive Bayes classifier), benchmarked against mothur and QIIME 2. Presented as a poster at **ECCB 2026** (Geneva). [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23325860.svg)](https://doi.org/10.5281/zenodo.23325860) · [live demo](https://demo.bioagens.com)
- **[Actopan microbiome](https://github.com/mijailcampos/actopan-microbiome-16S-18S)**: prokaryotic and eukaryotic communities in oysters (*Crassostrea virginica*), river water and human feces from Chachalacas, Veracruz (PhD project, manuscript in preparation).
- **Bioagens**: a set of web GUIs for QIIME 2, mothur, assembly, variant calling, RNA-seq and more, running on self-hosted infrastructure.
- Exploring **deep learning on DNA sequences** (embeddings + clustering for taxonomic assignment).
